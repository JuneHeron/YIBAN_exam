# 学生手册题库

把反复模拟考的题目攒成本地题库：自动去重、可检索、可刷题。单文件 SQLite，只用 Python 标准库。

> 这是一个**本机运行的学习辅助工具**：题库是你自己一条条采集出来的，只监听 `127.0.0.1`，
> 不联外网、不含任何平台凭据。使用前请先读文末的[免责声明与使用范围](#免责声明与使用范围)。

```
<项目文件夹>\
  问答案.bat   双击这个就能用（ask.bat 是同一个东西的英文名）
  ask.py       粘贴出答案的窗口
  bank.db      题库（单文件，备份就复制它；第一次跑会自动建）
  bank.py      工具
  README.md    本文件
  NOTES.md     平台相关的观察记录
  开发须知.md   改代码前看：踩过的坑、验证方法、设计决定
  油猴/        油猴脚本：自动查库答题 + 采集入库（见 油猴/README.md）
```

## 前提与思路

这套东西是围绕两个**平台特性**设计的，缺一个它就不成立了：

1. **模拟考能反复做，次数基本不受限。** 所以「把题库摸完」是有终点的——
   反复考几轮，`stats` 里「只出现过一次」不再增长就说明覆盖得差不多了。
2. **交卷后会公布每道题的正确答案。** 这是整个项目成立的关键：它意味着
   蒙对的题也能拿到正确答案，采集一次就永久留下，**不需要你答对**。
   采集只在试卷页做（`正确答案：X` 就在那儿），答题时完全不写库。

于是策略就是：**先花几轮把库摸全，再靠库去考。** 一次没答满分不要紧，
交卷后采集一次，下一轮那几道就对了。这也解释了为什么没有手工录题功能——
题目只从试卷页采集这一条路，够用了。

> 采集的是「题目 + 正确答案」，所以**第一次考几乎必然不满分**，这是设计内的一环，
> 不是 bug。

## 怎么开始（三步，不用命令行）

**第 0 步：装 Python**（一次性，约 30MB）。到 <https://www.python.org/downloads/> 下载
Windows 安装包，安装界面第一步**务必勾选 `Add python.exe to PATH`**。

**第 1 步：双击 `start.bat`。** 会弹出一个黑色窗口，别关它——它就是题库服务。
同时浏览器会自动打开一个说明页。

**第 2 步：按说明页上的三步做。** 装油猴扩展 → 点页面上的链接装脚本 →
打开考试页面，右下角出现面板。

**第 3 步：攒题。**

1. 考试或模拟考**交卷后**，在试卷页点面板上的「**采集入库**」——它会遍历整份卷子，
   把每道题的「题目 + 正确答案」一次性收进题库
2. 反复考几轮，题库就摸全了（`stats` 里「只出现过一次」不再增长就差不多了）

> 服务窗口关了就得重新双击 `start.bat`。脚本里看到的「未连接」就是它没在跑。

考试开卷、允许查资料，所以这套东西可以直接用于考试时查询——这也是 `ask` 的设计目标：
**高置信才返回答案，查不到就明说查不到，绝不猜。**

## 考试时怎么用

**双击 `问答案.bat`**，然后把题目**连选项一起**粘进去，粘完打一个空行回车：

```
================================================================
  题库 234 题
  把题目粘进来（一定要连选项一起），粘完打一个空行回车 -> 出答案
  直接空回车 = 跳过这一道；输入 q 回车 = 退出
================================================================

粘题目，末尾空一行回车：
答案: B  → 两年   （题库里存的是 C，说明这次选项顺序不同，已按你看到的顺序重算）
      [完全相同 1.00] 新生和在校学生，应招参加中国人民解放军…至退役后几年()
```

出完答案窗口不关，可以接着粘下一道；输入 `q` 回车退出。

双击没反应就是 `python` 不在系统路径里：在项目文件夹的地址栏输入 `cmd` 回车打开命令行，
手动跑 `python ask.py`，不行就换 `py ask.py`。`python bank.py ask` 是等价的单次查询版。

**关键纪律：一定要连选项一起粘。** 原因见下节。

## 查询（命令行版）

```
python bank.py ask
```

回车后把整道题粘进去（连选项一起），**再打一个空行回车**就出答案。
不用加引号，不用手工剥选项——选项行、题号、`正确答案：X` 都会被自动忽略，只拿题干去匹配。

### 为什么必须连选项一起粘

**平台每次进入会打乱选项顺序，所以字母不能照抄题库里的。** 题库里存的字母只对当时那次录入的顺序有效，
真正稳定的只有「正确选项的原文」。连选项一起粘，工具才能按**你这次看到的顺序**重算字母：

| 你粘进来的顺序 | 输出 |
| --- | --- |
| A.一年 B.三年 C.两年 D.四年 | `答案: C → 两年` |
| A.三年 B.两年 C.四年 D.一年 | `答案: B → 两年`（库里存的是 C，已重算） |
| A.一年 B.三年 C.四年 D.两年 | `答案: D → 两年`（库里存的是 C，已重算） |

只给题干不给选项时，它**不会编一个字母给你**，而是只报选项原文并警告，因为字母无从校对：

```
选项原文: 两年
      !! 无法确定字母：你只给了题干没给选项，无法校对顺序——请按上面的选项原文作答
```

多选会重算并排成升序（`ABCDE`）。选项措辞与库里对不上时会明说找不到，同样只给原文。

`ask` 默认阈值 0.85，低于就打印「题库无此题」——**它不会猜**。多道题都命中时会全部列出来，
那种情况说明题干太短，看题干和选项确认是哪一道。

`find` 是宽松版（阈值 0.5），标出 `完全相同` / `片段包含` / `被包含` / `近似`，用于自己对账。

## 去重与答案冲突

- `stem_key` = 题干规范化的 SHA1。规范化剥掉：全角转半角（NFKC）、**所有标点**（按 Unicode
  类别 P*/Z*，不是枚举具体字符）、空白、转小写，以及开头的题号。标点之所以要剥，是因为同一道题
  在不同次模拟里引号括号写法会变（`""` 与 `「」`、`()` 与 `（）`、全角半角逗号）。
- **题目身份默认只取题干，不含选项**，因为选项顺序可能被打乱、措辞也会微调，题干才稳定。
  **但有一类例外**：题干是纯套话时（`下列说法错误的是` 这类），光靠题干撑不起身份——
  平台同一句套话下可能有好几道不同的题，合并就会让答案互相覆盖。这类题会把**选项集合**
  （排序后取，所以打乱顺序仍算同一道）也算进身份。
- 重复命中不新建行，只把 `times_seen + 1`。所以 `times_seen` 高的就是高频题。
- 去重盖不住的唯一情况是**平台改写了题干**（同一考点换个问法），那会被当成两道题分别收录。
  这是刻意的：题干正是判定同一道题的依据，放宽就会把不同的题误判成一道。

**答案存两份**：`answer` 存字母，`answer_text` 存选项原文（`携带小抄 / 交头接耳`）。
不少平台每次进入会打乱选项顺序，一旦打乱字母答案就废了，而选项原文永远对。

**两次录入答案不一致时不会覆盖**，原答案保留，冲突记进 `conflicts` 表并当场提示：

```
python bank.py conflicts
```

这条很重要：几十次模拟下来一定会有答案打架的情况（可能是抄错，也可能是平台自己的答案键不一致）。
静默覆盖会让题库烂掉，而考试时一个错答案比没答案更糟。

**冲突比较的是「答案的选项原文」，不是字母。** 因为平台打乱选项后，同一个正确选项会落到别的字母上。
只比字母的话，每次打乱都会误报冲突。字母不同但选项原文一致 = 同一答案，按正常更新处理
（字母和选项一起刷新，保证两者始终对得上同一次顺序）。

## 采集时会报的两种重复

**同一场考试内重复**是判定「平台题库自己就有重复条目」的硬证据，会单独报出来；
**跨场重复**只说明你在覆盖同一个池子，正常。含义与用法见 `NOTES.md`。

## 清空题库

```bash
python bank.py clear            # 预览：列出各来源有多少题
python bank.py clear --all --yes # 真删（删前自动备份）
```

默认只预览，**真删前一定自动备份**成 `bank-日期时间.bak.db`，并告诉你还原方法。
面板上也有「清空题库」按钮，走同一条路（先问范围、再确认、服务端备份）。

## 刷题与进度

```bash
python bank.py quiz --n 30
python bank.py stats
python bank.py dupes          # 疑似重复的题目对（候选，需人工判断）
```

`quiz` 按 `wrong_count DESC, right_count ASC` 出题，做错的题下次排前面。
判分能容忍全角、小写、空格（`a b` 等同 `AB`）。

`stats` 里的几个数字是覆盖度信号：

| 指标 | 含义 |
| --- | --- |
| 只出现过一次 | 还没被模拟考覆盖到，这个数不再增长说明题库摸完了 |
| 出现 3 次以上 | 高频题，优先背 |
| 答案冲突 | 必须清零，否则库里有错答案 |

`dupes` 只输出事实（题干相似度、选项文本重合度、两侧答案的选项原文），**结论由人下**——
文本相似度无法判定是否同一道题，已知的两种骗人情形见 `NOTES.md`。

备份：`python bank.py export --out bank.json`，或直接复制 `bank.db`。

## 已知局限（先说清，别踩了再回来找）

- **只在一个平台上验证过：易班的学生手册考试。** 页面结构（`油猴/README.md` 里有记录）
  是照着那一个考试种类调的。换成别的考试种类、别的学校，或者平台改版，
  识别规则很可能要重新适配——面板上的「诊断」就是为此准备的。
- **题库里有几道题的答案是错的。** 来源可能是采集时抄错，也可能是平台自己的答案键
  不一致（同一道题在不同次数里给了不同答案）——后者会被 `conflicts` 记下来，
  前者不会。**这几道我没有继续修**：反复刷几轮之后，错的那几道靠重考就能覆盖掉，
  已经够用，继续为它投入不划算。所以请把 `python bank.py conflicts` 当成一个
  该定期看的清单，而不是「没有冲突就等于全对」。
- **`ask` 宁可说「查不到」也不猜**，所以题库没覆盖到的题它会明说没这题；
  而脚本遇到没覆盖的题会**随机选**。指望一次满分不现实，多来几轮。

## 免责声明与使用范围

**这个工具解决的是「手动翻书太慢」，不是「替你把考试考了」。**

- 题目全部来自你自己在页面上采集的内容，题库是本地单文件 `bank.db`，**不含任何平台账号、
  密码、Cookie 或令牌**，桥接服务也只绑 `127.0.0.1`，外网访问不到。
- 脚本**不自动交卷**，人机验证必须人工过。答题的每一步都是你自己触发的。
- 查询策略是**宁可不答也不猜**：低于置信阈值就明确返回「题库无此题」。
  题库里没有的题会随机选——所以**别把它当考试时的唯一依据**。
- 平台可能检测自动化脚本，**不保证不被判定为异常**，请自行评估并遵守你所在学校/平台的
  考试规则。用它参加明令禁止使用辅助工具的考试，后果由使用者自负。
- 代码按 MIT 协议开源，**不提供任何担保**。

> 如果你是老师或平台方，希望了解这套东西是怎么工作的：请读 `NOTES.md`（平台相关观察）
> 和 `油猴/README.md`（脚本原理与已知风险），那里把识别规则和限制都写明了。
